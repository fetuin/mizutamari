# 雨上がりの水路

雨上がりの校庭に残った水たまりを、溝を掘って側溝まで流すブラウザゲームです。
かちかちの地面には木の棒で細い筋しか引けませんが、水が通った土はやわらかくなり、手で溝を広げられるようになります。

開発元: [usePocket](https://usepocket.com)

## 遊び方

- **木の棒**: どんなにかたい土でも、幅4cmほどの細い筋を少しずつ掘れる
- **手**: やわらかくなった土だけ、幅12cmほどを一気にかき出せる
- 掘った土は溝のわきに積もる
- 水たまりの85%を側溝へ流せばクリア。掘った土が少ないほど星が増える
- 場所は10か所（朝礼台の前、鉄棒の下、水飲み場の前、トラックのカーブ、ブランコの下、体育倉庫の裏、砂場のそば、サッカーゴール前、のぼり棒のまわり、百葉箱の横）

## フォルダ構成

| パス | 内容 |
|---|---|
| `index.html` | ゲーム本体（HTML 1ファイル完結。星とタイムの記録はブラウザ内に保存） |
| `counter.cgi` | アクセスカウンター（Perl CGI。鍵メモのガイドページと同じもの） |
| `counter_data/.htaccess` | カウンターデータを外から読めなくする設定 |

## 設置方法

`index.html`、`counter.cgi`、`counter_data/` を同じフォルダにアップロードします。

- `counter.cgi` は 755、`counter_data` は 755（書き込めなければ 707 か 777）
- カウンターのページタグは `mizutamari` です（`index.html` 冒頭の `data-page`）
- すでに別の場所に `counter.cgi` を置いている場合は、それを使えます。`index.html` の `data-src` をそのCGIのURLに書き換え、ここの `counter.cgi` と `counter_data/` はアップロードしなくてかまいません
- カウンターに届かないとき（ローカルでファイルを直接開いたときなど）は、上部のアクセス数の帯が自動で隠れます

## 注意

- `counter.cgi` の `$HASH_SALT` はリポジトリでは初期値のままです。サーバーに置くものは任意の文字列に変えてください
- カウンターの記録データ（`counter_data/*.dat`）と管理用パスワード（`counter_data/admin_password.txt`）はリポジトリに入れません
